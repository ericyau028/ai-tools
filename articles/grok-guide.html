Grok AI 繁體中文完整教學：功能、圖片生成與使用技巧

AI Tools Hub 編輯部 · 2026-08-08 · 約 9 分鐘閱讀 Grok 新手入門

📌 本文重點（30 秒速讀）

  • Grok 是 xAI（Elon Musk 創辦）打造的 AI 助手，主打即時資訊與直白風格
  • Grok 4 支援長上下文、圖片生成與深度推理
  • 深度整合 X（Twitter）平台，可即時分析社群動態
  • 提供網頁版、App 與 API，部分功能需 X Premium 訂閱

什麼是 Grok？

Grok 是由 xAI（Elon Musk 於 2023 年創立的 AI 公司）開發的對話式 AI 助手。名稱取自科幻小說《銀河便車指南》中的「Grok」一詞，意為「深刻理解」。

Grok 最大的特色是能即時存取 X（Twitter）平台上的最新資訊，並以較為直白、幽默甚至帶點「叛逆」的語氣回應，與其他追求「政治正確」的 AI 形成鮮明對比。

Grok 模型家族

Grok 系列持續演進，目前主要版本如下：

🧠 Grok 4

最新旗艦模型，強化推理與長上下文能力，支援圖片生成與深度思考模式，是 xAI 目前最強的主力模型。

⚡ Grok 4 Fast

強調速度與效率的版本，回應更快，適合需要即時互動的場景，犧牲部分深度推理換取低延遲。

🖼️ Grok Imagine

專注圖片生成的模型，可依文字描述產生高品質圖像，並支援風格化與編輯。

Grok 核心功能

📡 即時資訊

直接存取 X 平台即時動態，可分析最新新聞、趨勢與熱門話題，回答「現在發生什麼事」類型的問題。

🖼️ 圖片生成

內建圖片生成能力，可依文字描述產生圖像，並支援上傳圖片進行分析與編輯。

💭 深度思考

Grok 4 支援深度思考模式，在回答複雜問題前先進行內部推理，提升邏輯與準確度。

🔗 X 深度整合

與 X 平台深度整合，可分析貼文、回覆與帳號，適合社群經營與輿情分析。

快速開始

使用方式

  1. 前往 Grok 官方網站（grok.com）或使用 X 平台內建的 Grok 入口
  2. 使用 X（Twitter）帳號登入
  3. 免費版有基本使用額度，進階功能需 X Premium 訂閱
  4. 開始對話，支援繁體中文與圖片上傳

💡 提示：Grok 的免費額度有限，若要完整使用圖片生成與深度思考功能，通常需要 X Premium 或 SuperGrok 訂閱。

申請 Grok API

  1. 前往 xAI 官方 API 平台（console.x.ai）
  2. 註冊並建立 API Key
  3. 選擇模型（grok-4 或 grok-4-fast）
  4. 免費版有一定額度，付費版按量計費

基本 API 串接範例

from openai import OpenAI

client = OpenAI(
    api_key="your-xai-api-key",
    base_url="https://api.x.ai/v1"
)

response = client.chat.completions.create(
    model="grok-4",
    messages=[{"role": "user", "content": "請用繁體中文介紹 Grok 的特色。"}]
)

print(response.choices[0].message.content)

善用即時資訊

Grok 的強項是即時資訊，可這樣運用：

  • 結合即時資訊與推理，可獲得兼具時效性與深度的回答

常見問題

Grok 免費嗎？

有免費版，但額度有限。完整功能（圖片生成、深度思考）通常需要 X Premium 或 SuperGrok 訂閱。

Grok 和 ChatGPT 差在哪？

Grok 主打即時 X 資訊與直白風格，ChatGPT 生態系與外掛較成熟。Grok 在即時資訊與社群分析上有優勢。

Grok 支援中文嗎？

支援，繁體與簡體中文皆可，但中文能力與 ChatGPT、Gemini 相比仍有一定差距。

Grok 一定要用 X 帳號嗎？

網頁版與 App 通常需要 X 帳號登入。API 則可獨立註冊 xAI 帳號使用。
