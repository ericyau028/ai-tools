ChatGPT 完整教學：從基礎到進階應用

AI Tools Hub 編輯部 · 2026-07-20 · 約 15 分鐘閱讀 ChatGPT 新手入門

📌 本文重點（30 秒速讀）

  • ChatGPT 有免費版和 Plus 版（$20/月），差別在於 GPT-4 存取權
  • 寫提示詞的核心原則：明確具體、分步驟、給範例
  • 進階功能：GPT-4 多模態可分析圖片、Advanced Data Analysis 可處理 Excel 和 PDF
  • 自訂 GPTs 可以打造專屬 AI 助手，不需寫程式

ChatGPT 是什麼？

ChatGPT 是由 OpenAI 開發的對話式 AI 助手。2026 年的 ChatGPT 已整合 GPT-4 多模態模型，支援文字、圖像、語音等多種互動方式。

它可以用來寫文章、寫程式、翻譯、分析資料、腦力激盪等，是目前全球用戶最多的 AI 產品。

開始使用 ChatGPT

註冊與方案選擇

使用 ChatGPT 的第一步只要 3 分鐘：

  1. 前往 chat.openai.com 點擊「註冊」
  2. 登入方式：Google 帳號、Microsoft 帳號或 Email
  3. 選擇方案：免費版（GPT-3.5）或 Plus（$20/月，含 GPT-4）

💡 建議：先從免費版開始試用，確認 ChatGPT 對你有用再升級 Plus。

介面導覽

ChatGPT 的主要介面分三個區域：

  • 左側邊欄 — 對話歷史、自訂 GPTs 列表、設定
  • 中央對話區 — 顯示對話內容，支援 Markdown 和程式碼高亮
  • 底部輸入框 — 輸入文字，可附加圖片、PDF、文字檔

提示詞工程入門

寫出好的提示詞是使用 ChatGPT 的核心技能。掌握基本原則後，效果會差很多。

三個基本原則

🎯 明確具體

不要只說「寫一篇文」，要說「寫一篇 500 字的繁體中文產品介紹，對象是 30 歲上班族」

📝 分步驟引導

複雜任務拆成多步驟，例如「先列出大綱 → 再展開每個章節 → 最後總結」

📋 給範例

提供一個你想要的輸出範例，ChatGPT 會模仿你的語氣和格式

實用提示詞範例

「你是一位專業的繁體中文編輯。請幫我修正以下文章的語法錯誤和錯字，保持原意不變，只輸出修正後的版本：[貼上文章]」

「請用表格比較 ChatGPT、Deepseek 和 Claude AI 的優缺點，包含價格、功能、適合族群三欄」

進階功能

GPT-4 多模態

Plus 用戶可以上傳圖片給 ChatGPT 分析。例如：拍一張冰箱照片，請它推薦食譜。

✅ 實際應用：拍報表截圖 → ChatGPT 分析數據 → 產出 Excel 公式

Advanced Data Analysis

上傳 Excel、CSV、PDF 等檔案，ChatGPT 會自動分析數據並生成圖表。

  • 📊 上傳銷售數據 → 自動產生趨勢圖
  • 📄 上傳合約 PDF → 摘要重點條款
  • 📝 上傳手寫筆記照片 → 轉成文字

自訂 GPTs

不需寫程式就能打造專屬 AI 助手。設定好指令和知識庫後，分享給他人使用。

📚 寫作助手 GPT

設定你的寫作風格 → 上傳參考文章 → 每次輸出的文章都符合你的語氣

💼 簡報顧問 GPT

上傳你的簡報內容 → 自動生成大綱、講稿、QA 預測

實用技巧

  • 🔹 新對話新主題 — 每次新任務開新對話，避免舊對話影響新回答
  • 🔹 不滿意就追問 — 說「再來一個版本」「更簡潔一點」「用表格呈現」
  • 🔹 指定角色 — 「你是一位資深行銷專家」「你是一位 Python 工程師」
  • 🔹 常用指令存起來 — 把常用的提示詞存成筆記，需要時直接貼上

⚠️ 注意：ChatGPT 的回答可能包含錯誤，特別是涉及最新資訊時。重要決策建議自行查證。

常見問題

ChatGPT 和 Deepseek 哪個比較好？

看需求。ChatGPT 多模態強（圖像辨識），Deepseek 上下文長（1M Token）且免費。建議兩個都用。

ChatGPT Plus 值得升級嗎？

如果你每天使用超過 2 小時，或需要圖像分析、檔案處理等功能，就值得。輕度用戶免費版就夠了。

ChatGPT 會取代我的工作嗎？

不會取代你，但會取代「不會用 AI 的人」。建議把 ChatGPT 當成助手，不是替代品。

總結

  • ✅ 免費版就能體驗 ChatGPT 的基本功能
  • ✅ Plus 版解鎖 GPT-4 多模態和資料分析
  • ✅ 提示詞越具體，回答越有用
  • ✅ 善用自訂 GPTs 打造專屬助手
  • ✅ 重要資訊記得自行驗證

GPT-4 進階功能

多模態互動

GPT-4 支援多模態輸入，你可以：

  • 上傳圖片進行分析（如圖表解讀、產品照片分析）
  • 上傳 PDF、Word、Excel 等文件進行內容提取與分析
  • 使用語音輸入進行對話（手機 App）
  • 生成圖像（需使用 DALL·E 3 整合功能）

Advanced Data Analysis

此功能（原名 Code Interpreter）讓 ChatGPT 可以執行 Python 程式碼來進行數據分析：

  1. 上傳 CSV 或 Excel 資料檔案。
  2. 要求 ChatGPT 進行數據清洗、分析、統計。
  3. ChatGPT 會自動生成並執行 Python 程式碼。
  4. 結果以圖表、表格或文字形式呈現。
實戰場景：上傳銷售數據，要求「分析季度趨勢並預測下季表現」，ChatGPT 會自動完成數據處理與視覺化。

自訂 GPTs

GPTs 是 ChatGPT 的客製化版本，你可以建立專屬的 AI 助手：

  • 知識庫：上傳文件建立專屬知識庫（如公司手冊、技術文件）。
  • 指令設定：設定系統提示詞，定義 GPT 的行為模式。
  • 功能整合：啟用 Web Browsing、DALL·E、Code Interpreter 等能力。
  • Actions：串接外部 API，實現與第三方服務的互動。

建立 GPTs 的方法：

  1. 在 ChatGPT 左側欄點擊「Explore GPTs」。
  2. 點擊「Create」進入 GPT Builder。
  3. 透過對話或手動設定來配置 GPT。
  4. 發佈後可分享連結給他人使用。

API 串接

對於開發者，OpenAI API 提供了強大的整合能力：

API 申請

  1. 前往 platform.openai.com 註冊開發者帳號。
  2. 進入 API Keys 頁面建立 API Key。
  3. 設定用量限制與帳單資訊。
  4. 查看 API 文件了解具體用法。

Python 串接範例

from openai import OpenAI

client = OpenAI(api_key="your-api-key")

response = client.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "system", "content": "你是一個專業的繁體中文助手。"},
        {"role": "user", "content": "請解釋機器學習的基本概念。"}
    ],
    temperature=0.7,
    max_tokens=1000
)

print(response.choices[0].message.content)

實戰應用案例

內容創作

ChatGPT 在內容創作上的應用：

  • 部落格文章：提供大綱後，ChatGPT 可生成完整文章並進行 SEO 最佳化。
  • 社群媒體：生成多個版本的貼文文案，適用於不同平台。
  • 翻譯與本地化：高品質的多語言翻譯，支援術語一致性。
  • 摘要生成：將長文檔濃縮為重點摘要。

程式開發

ChatGPT 已成為程式開發者的重要工具：

  • 程式碼生成與除錯
  • 程式碼審查與最佳化建議
  • 撰寫單元測試
  • 技術文件撰寫
  • 資料庫查詢生成

數據分析

透過 Advanced Data Analysis，ChatGPT 可以：

  • 數據清洗與預處理
  • 統計分析與假設檢定
  • 圖表生成與視覺化
  • 機器學習模型建立
  • 報告自動生成

實用技巧

  • 溫度參數：創造性任務設高溫度（0.8-1.0），精確任務設低溫度（0-0.3）。
  • 對話上下文：ChatGPT 會記住當前對話的上下文，但長對話後可能遺忘早期內容。
  • 定期匯出對話：重要的對話可匯出保存，避免遺失。
  • 使用 Projects：ChatGPT Plus 用戶可使用 Projects 功能組織相關對話。
  • 自訂指令：在設定中可設定全局自訂指令，影響所有對話。

結語

ChatGPT 已從單純的對話機器人發展為全能型的 AI 生產力平台。掌握提示詞工程、善用 GPT-4 進階功能並熟悉 API 串接，將能最大化 ChatGPT 在工作和生活中的價值。
