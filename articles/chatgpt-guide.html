ChatGPT 完整教學：從基礎到進階應用

AI Tools Hub 編輯部 · 2026-07-20 · 約 15 分鐘閱讀 ChatGPT 新手入門

ChatGPT 是什麼？

ChatGPT 是由 OpenAI 開發的對話式 AI 助手，自 2022 年底推出以來已成為全球用戶最多的 AI 產品。2026 年的 ChatGPT 已整合 GPT-4 多模態模型，支援文字、圖像、語音等多種互動方式，並提供自訂 GPTs、Advanced Data Analysis、Plugin 等豐富功能。

開始使用 ChatGPT

註冊與方案選擇

使用 ChatGPT 的第一步：

  1. 前往 chat.openai.com 點擊「註冊」。
  2. 可透過 Google 帳號、Microsoft 帳號或 Email 註冊。
  3. 註冊完成後選擇方案：免費版（GPT-3.5）或 ChatGPT Plus（$20/月，含 GPT-4）。
  4. 企業用戶可選擇 ChatGPT Team（$25/人/月）或 ChatGPT Enterprise。
建議：若需要處理複雜任務、程式開發或多模態功能，建議升級至 ChatGPT Plus。

介面導覽

ChatGPT 的主要介面包含以下區域：

  • 左側邊欄：對話歷史記錄、自訂 GPTs 列表、設定選項。
  • 中央對話區：顯示對話內容，支援 Markdown、程式碼高亮、圖片顯示。
  • 底部輸入框：輸入提示詞，可附加檔案（圖片、PDF、文字檔等）。
  • 模型選擇器：切換 GPT-4、GPT-4o、GPT-3.5 等模型。

提示詞工程入門

寫出好的提示詞是使用 ChatGPT 的核心技能：

基本原則

原則 說明 範例
明確具體 提供足夠的上下文與要求 「請用繁體中文寫一封正式的商務郵件，主旨為合作提案」
分步驟引導 將複雜任務拆解為多個步驟 「第一步：分析需求；第二步：設計方案；第三步：寫程式碼」
指定角色 給予 AI 明確的角色設定 「你是一個資深的 Python 開發者」
提供範例 給出期望的輸出範例 「請按照以下格式輸出：{名稱}：{說明}」

GPT-4 進階功能

多模態互動

GPT-4 支援多模態輸入，你可以：

  • 上傳圖片進行分析（如圖表解讀、產品照片分析）
  • 上傳 PDF、Word、Excel 等文件進行內容提取與分析
  • 使用語音輸入進行對話（手機 App）
  • 生成圖像（需使用 DALL·E 3 整合功能）

Advanced Data Analysis

此功能（原名 Code Interpreter）讓 ChatGPT 可以執行 Python 程式碼來進行數據分析：

  1. 上傳 CSV 或 Excel 資料檔案。
  2. 要求 ChatGPT 進行數據清洗、分析、統計。
  3. ChatGPT 會自動生成並執行 Python 程式碼。
  4. 結果以圖表、表格或文字形式呈現。
實戰場景：上傳銷售數據，要求「分析季度趨勢並預測下季表現」，ChatGPT 會自動完成數據處理與視覺化。

自訂 GPTs

GPTs 是 ChatGPT 的客製化版本，你可以建立專屬的 AI 助手：

  • 知識庫：上傳文件建立專屬知識庫（如公司手冊、技術文件）。
  • 指令設定：設定系統提示詞，定義 GPT 的行為模式。
  • 功能整合：啟用 Web Browsing、DALL·E、Code Interpreter 等能力。
  • Actions：串接外部 API，實現與第三方服務的互動。

建立 GPTs 的方法：

  1. 在 ChatGPT 左側欄點擊「Explore GPTs」。
  2. 點擊「Create」進入 GPT Builder。
  3. 透過對話或手動設定來配置 GPT。
  4. 發佈後可分享連結給他人使用。

API 串接

對於開發者，OpenAI API 提供了強大的整合能力：

API 申請

  1. 前往 platform.openai.com 註冊開發者帳號。
  2. 進入 API Keys 頁面建立 API Key。
  3. 設定用量限制與帳單資訊。
  4. 查看 API 文件了解具體用法。

Python 串接範例

from openai import OpenAI

client = OpenAI(api_key="your-api-key")

response = client.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "system", "content": "你是一個專業的繁體中文助手。"},
        {"role": "user", "content": "請解釋機器學習的基本概念。"}
    ],
    temperature=0.7,
    max_tokens=1000
)

print(response.choices[0].message.content)

實戰應用案例

內容創作

ChatGPT 在內容創作上的應用：

  • 部落格文章：提供大綱後，ChatGPT 可生成完整文章並進行 SEO 最佳化。
  • 社群媒體：生成多個版本的貼文文案，適用於不同平台。
  • 翻譯與本地化：高品質的多語言翻譯，支援術語一致性。
  • 摘要生成：將長文檔濃縮為重點摘要。

程式開發

ChatGPT 已成為程式開發者的重要工具：

  • 程式碼生成與除錯
  • 程式碼審查與最佳化建議
  • 撰寫單元測試
  • 技術文件撰寫
  • 資料庫查詢生成

數據分析

透過 Advanced Data Analysis，ChatGPT 可以：

  • 數據清洗與預處理
  • 統計分析與假設檢定
  • 圖表生成與視覺化
  • 機器學習模型建立
  • 報告自動生成

實用技巧

  • 溫度參數：創造性任務設高溫度（0.8-1.0），精確任務設低溫度（0-0.3）。
  • 對話上下文：ChatGPT 會記住當前對話的上下文，但長對話後可能遺忘早期內容。
  • 定期匯出對話：重要的對話可匯出保存，避免遺失。
  • 使用 Projects：ChatGPT Plus 用戶可使用 Projects 功能組織相關對話。
  • 自訂指令：在設定中可設定全局自訂指令，影響所有對話。

結語

ChatGPT 已從單純的對話機器人發展為全能型的 AI 生產力平台。掌握提示詞工程、善用 GPT-4 進階功能並熟悉 API 串接，將能最大化 ChatGPT 在工作和生活中的價值。
