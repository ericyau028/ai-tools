Google Gemini 繁體中文完整教學：從入門到進階

什麼是 Google Gemini？

Gemini 是 Google DeepMind 打造的原生多模態 AI 模型系列，從 Gemini 2.0 演進到 Gemini 2.5，是目前 Google 最強的主力模型。

與多數聊天機器人不同，Gemini 從一開始就以「多模態」為設計核心，能同時理解文字、圖片、音訊、影片與 PDF，加上 1M Token 的超長上下文，讓它成為分析大型資料與程式碼庫的利器。

Gemini 2.5 模型家族

Gemini 2.5 系列涵蓋不同需求，從頂尖推理到低成本大量調用都有對應選擇：

🧠 Gemini 2.5 Pro

旗艦思考模型，擅長程式、數學與 STEM 複雜推理，可分析大型資料集與程式碼庫。輸入上限 1M Token、輸出 65,536 Token。

⚡ Gemini 2.5 Flash

混合推理模型，支援 1M Token 上下文與可調思考預算，在品質、成本與延遲間取得平衡，適合日常複雜任務。

💰 Gemini 2.5 Flash-Lite

最小、最省成本的模型，專為大規模調用設計，輸入每 1M Token 僅 $0.10 美元，適合高吞吐量場景。

Gemini 2.5 核心功能

📚 1M Token 超長上下文

單次對話可輸入最多 100 萬 Token，約等於整本《白鯨記》或數百頁技術文件，也能一次塞入整個程式碼庫進行分析。

🎬 原生多模態理解

直接輸入圖片、音訊、影片（最多約 3 小時）與 PDF。可請 Gemini 分析圖片內容、整理影片重點，無需預處理。

💭 思考（Thinking）能力

內建 Chain-of-Thought 推理，可自訂思考預算在品質與成本間取捨。在 Humanity's Last Exam、GPQA 等基準名列前茅。

🔧 工具串接

支援 Function Calling、程式執行、Google 搜尋與地圖 grounding、結構化輸出，可打造 Agentic 應用。

快速開始

使用網頁版

最簡單的使用方式：

  1. 前往 Gemini 官方網站（gemini.google.com）
  2. 使用 Google 帳號登入
  3. 選擇模型（Gemini 2.5 Pro 或 Flash）
  4. 開始對話，支援繁體中文與圖片/檔案上傳

💡 提示：網頁版免費且無明顯使用次數限制，適合一般使用者。開發者若要大量調用或整合進產品，建議使用 Gemini API。

申請 Gemini API

  1. 前往 Google AI Studio（aistudio.google.com）
  2. 使用 Google 帳號登入，點擊「Get API key」
  3. 複製 API Key 並妥善保存
  4. 免費版有一定額度，付費版按量計費

基本 API 串接範例

以下是一個使用官方 SDK 的 Python 範例：

from google import genai

client = genai.Client(api_key="your-gemini-api-key")

response = client.models.generate_content(
    model="gemini-2.5-pro",
    contents="請用繁體中文解釋何謂長上下文（Long Context）。"
)

print(response.text)

提示詞技巧

以下是一些針對 Gemini 的提示詞最佳實踐：

結構化提示詞

Gemini 對結構清晰的提示詞回應品質較高：

## 任務
分析下列 10 份 PDF 文件的重點

## 要求
- 輸出繁體中文
- 用條列式整理每個文件的核心結論
- 標註文件之間的共通主題
- 最後提供一份 200 字總結

啟用思考模式

  • 直接使用「請逐步思考再回答」
  • 設定思考預算來控制深度與成本
  • 對需要嚴格邏輯的任務（數學、程式）效果特別明顯

實際應用案例

💻 程式碼庫分析

利用 1M Token 上下文直接輸入整個 repo，請 Gemini 理解架構、找出 bug 或撰寫測試，大幅提升開發效率。

🎞️ 影片與會議記錄

上傳長達數小時的影片或錄音，Gemini 能輸出逐字重點、行動項目與討論摘要。

📄 合約與研究論文

一次分析多份 PDF，提取關鍵條款、交叉比對並找出潛在風險。

🌐 多語系內容在地化

Gemini 在 Global MMLU 多語系基準表現優異，適合翻譯、文案在地化與跨語系 SEO。

常見問題

Gemini 網頁版免費嗎？

是，gemini.google.com 網頁版免費使用。API 有免費額度，超過後按量計費。

Gemini 和 ChatGPT 哪個比較好？

兩者各有擅長。Gemini 的 1M Token 長上下文與 Google 服務整合是其優勢；ChatGPT 生態系與外掛較成熟。建議依任務選擇。

Gemini 支援中文嗎？

支援，繁體與簡體中文皆可，且多語系能力優異。

Gemini API 商用有授權限制嗎？

透過 Gemini API 使用時，Google 的服務條款允許商用，請依官方條款規範使用。
