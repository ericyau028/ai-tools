Cursor AI 繁體中文教學｜AI 程式編輯器入門

AI Tools Hub 編輯部 · 2026-07-24 · 約 10 分鐘閱讀 Cursor 程式開發

什麼是 Cursor？

Cursor 是一款以 AI 為核心驅動的程式碼編輯器，基於 VS Code（Visual Studio Code）的分支開發，保留了 VS Code 的所有功能與擴充生態系，同時深度融合了 AI 輔助程式設計能力。簡單來說：Cursor 就是將 ChatGPT / Claude 的程式碼能力直接內建到編輯器中。

由 Anysphere 公司開發的 Cursor，在 2025-2026 年間迅速崛起，成為開發者社群中最受歡迎的 AI 程式碼編輯器之一。其最大特色是將大型語言模型（LLM）無縫整合到開發流程中，讓開發者不需切換視窗即可完成程式碼生成、修改、除錯與重構。

安裝與設定

下載安裝

前往 Cursor 官方網站（cursor.com）即可免費下載，支援以下平台：

  • Windows — 下載 .exe 安裝檔，雙擊安裝即可
  • macOS — 下載 .dmg 檔案，支援 Apple Silicon（M 系列）與 Intel 晶片
  • Linux — 提供 .AppImage / .deb / .rpm 等多種格式

匯入 VS Code 設定

由於 Cursor 基於 VS Code，安裝後可直接匯入 VS Code 的設定、擴充套件與快捷鍵：

  1. 開啟 Cursor，首次啟動會詢問是否從 VS Code 匯入設定。
  2. 選擇「Import from VS Code」，所有擴充套件、settings.json、快捷鍵將自動同步。
  3. 若已有 Cursor 專屬設定，可在設定頁面中調整 AI 相關選項。
提示：大部分 VS Code 擴充套件在 Cursor 上可直接使用，無需重新安裝。

註冊帳號與 AI 金鑰

Cursor 預設使用 Cursor 自有模型服務，註冊帳號後即可獲得免費額度。若想使用自己的 API Key（例如 GPT-4 或 Claude API），可在 Settings > Models 中設定。

核心功能

Chat — AI 對話面板

按下 Ctrl+I（Mac：Cmd+I）即可在側邊欄開啟 AI 對話面板。你可以像是在 ChatGPT 中一樣直接提問，但不同的是 Chat 能自動感知你當前開啟的檔案內容、選取的程式碼片段與專案結構。

適用場景：

  • 詢問程式碼片段的功能或用途
  • 請求解釋陌生語法或演算法
  • 取得單元測試範例
  • 討論架構設計方案

Composer — 多檔案編輯模式

Composer 是 Cursor 最強大的功能之一，允許 AI 同時編輯或建立多個檔案。按下 Ctrl+Shift+I（Mac：Cmd+Shift+I）即可開啟 Composer 面板。

你能直接對 Composer 下達需求，例如「建立一個 React Todo List 元件，包含新增、刪除與完成切換功能，並建立對應的 CSS 檔案」，Composer 會自動在專案中建立或修改多個檔案。

進階技巧：Composer 支援將專案文件作為上下文，讓 AI 理解整個專案結構後再進行修改。

Ctrl+K — 行內編輯

在編輯器中選取一段程式碼後按下 Ctrl+K（Mac：Cmd+K），即可直接對選取內容下達編輯指令。這是最常使用的功能之一，無需離開鍵盤即可完成程式碼修改。

常用指令範例：

  • 「Refactor this function to use async/await」
  • 「Add error handling」
  • 「Translate comments to English」
  • 「Optimize for performance」

AI 程式碼補全

Cursor 的 AI 補全功能類似 GitHub Copilot，在你輸入程式碼時會自動建議下一段內容。但 Cursor 的補全更加積極，甚至能一次預測多行或整個函式。所有建議以灰色文字顯示，按下 Tab 即可接受。

特色差異：

  • 跨檔案感知：補全建議基於整個專案上下文
  • 支援多種模型切換：可選擇不同 LLM 作為補全引擎
  • 即時反射：修改檔案後 AI 補全會立即調整建議

實戰範例

範例一：快速建立 React 元件

使用 Composer 輸入以下提示詞，立即生成完整的 React 元件：

Create a React component called "PricingCard" that:
1. Accepts title, price, features (array), and ctaText as props
2. Displays a pricing plan with a featured/highlighted variant
3. Includes Tailwind CSS classes for styling
4. Has proper TypeScript types
5. Export as default

Create the component in src/components/PricingCard.tsx

Composer 會自動建立檔案並填入完整的元件程式碼，包含 TypeScript 型別定義與 Tailwind CSS 樣式。

範例二：重構 Legacy 程式碼

選取一段舊有的 callback 風格程式碼，按下 Ctrl+K 並輸入：

Rewrite this using async/await, add proper TypeScript types, and split into smaller functions

Cursor 會直接在編輯器中修改選取的程式碼，並保留原有邏輯。

範例三：AI 輔助除錯

在 Chat 中貼上錯誤訊息並告訴 AI 你當前的程式碼邏輯，Chat 會根據錯誤訊息和你的程式碼提供具體的修復建議，並可直接「Apply」到編輯器中。

常見問題 FAQ

Cursor 與 VS Code 有什麼不同？

Cursor 基於 VS Code 原始碼，因此保留了 VS Code 的所有功能與擴充套件生態系。最大的差異在於 Cursor 深度整合了 AI 功能，如 Chat、Composer、Ctrl+K 和 AI 補全。你可以將 Cursor 視為「內建 AI 助手的 VS Code」。

Cursor 是免費的嗎？

Cursor 提供免費方案，包含每月 2,000 次 AI 補全與 500 次 Chat 訊息。若需無限制使用與高級模型配額，則需要升級至 Pro 方案（每月 $20 美元）。

可以用自己的 API Key 嗎？

可以。在 Cursor Settings > Models 中，你可以輸入自己的 OpenAI API Key、Anthropic API Key 或其他支援的 LLM 服務金鑰。自備 Key 的使用量不會計入 Cursor 的免費配額。

現有的 VS Code 擴充套件能繼續使用嗎？

絕大多數 VS Code 擴充套件在 Cursor 上可直接使用，包括 ESLint、Prettier、GitLens、Thunder Client 等。少數依賴 VS Code 專有 API 的擴充套件可能無法正常運作，但整體相容性極高。

Cursor 支援哪些程式語言？

Cursor 支援所有 VS Code 支援的程式語言，包括但不限於：JavaScript、TypeScript、Python、Java、Go、Rust、C/C++、Ruby、PHP、Swift、Kotlin 等。AI 功能對主流語言（JS/TS/Python/Go/Rust）的支援最佳。
