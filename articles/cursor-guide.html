什麼是 Cursor？

Cursor 是一款以 AI 為核心的程式碼編輯器，基於 VS Code 分支開發。它保留了 VS Code 的所有功能與擴充生態系，同時深度融合了 AI 輔助程式設計能力。

由 Anysphere 開發，Cursor 在 2025-2026 年間迅速崛起，成為開發者社群中最受歡迎的 AI 編輯器之一。最大特色是將大型語言模型無縫整合到開發流程中。

安裝與設定

下載安裝

前往 Cursor 官網（cursor.com）免費下載，支援三大平台：

  • Windows — 下載 .exe 安裝檔，雙擊安裝
  • macOS — 下載 .dmg，支援 Apple Silicon 與 Intel
  • Linux — 提供 .AppImage / .deb / .rpm 格式

匯入 VS Code 設定

Cursor 基於 VS Code，安裝後可直接匯入 VS Code 的設定、擴充套件與快捷鍵：

  1. 首次啟動時選擇「Import from VS Code」
  2. 所有擴充套件、settings.json、快捷鍵自動同步
  3. 可在設定頁面調整 AI 相關選項

💡 提示：大部分 VS Code 擴充套件在 Cursor 上可直接使用，無需重新安裝。

註冊帳號

Cursor 預設使用自有模型服務，註冊帳號後即可獲得免費額度。若想使用自己的 API Key（如 GPT-4 或 Claude），可在 Settings > Models 中設定。

核心功能

💬 Chat

按下 Ctrl+I 開啟 AI 對話面板，能自動感知當前檔案內容與選取的程式碼。

📂 Composer

按下 Ctrl+Shift+I 開啟，可同時編輯或建立多個檔案。

✏️ Ctrl+K

選取程式碼後按下 Ctrl+K，直接在編輯器內修改選取內容。

Chat — AI 對話面板

按下 Ctrl+I（Mac：Cmd+I）開啟側邊欄 AI 對話。Chat 能自動感知你當前的檔案內容、選取片段與專案結構。

適用場景：詢問程式碼功能、解釋陌生語法、取得測試範例、討論架構設計。

Composer — 多檔案編輯模式

Composer 是 Cursor 最強大的功能，允許 AI 同時編輯或建立多個檔案。按下 Ctrl+Shift+I（Mac：Cmd+Shift+I）開啟。

你可以直接下達需求，例如「建立一個 React Todo List 元件，包含新增、刪除與完成切換功能」，Composer 會自動建立或修改多個檔案。

✅ 進階技巧：Composer 支援將專案文件作為上下文，讓 AI 理解整個專案結構後再修改。

Ctrl+K — 行內編輯

選取程式碼後按下 Ctrl+K（Mac：Cmd+K），直接對選取內容下達編輯指令。這是最高頻使用的功能。

  • 「Refactor this function to use async/await」
  • 「Add error handling」
  • 「Optimize for performance」

AI 程式碼補全

類似 GitHub Copilot，在你輸入程式碼時自動建議下一段內容。Cursor 的補全更積極，能一次預測多行或整個函式。按下 Tab 接受建議。

實戰範例

⚛️ 快速建立 React 元件

用 Composer 輸入提示詞，立即生成完整的 React 元件，含 TypeScript 型別與 Tailwind 樣式。

🔄 重構 Legacy 程式碼

選取舊程式碼，按下 Ctrl+K 輸入重構指令，如「Rewrite using async/await」。

🐛 AI 輔助除錯

在 Chat 貼上錯誤訊息，AI 根據錯誤與程式碼提供修復建議，可直接 Apply 到編輯器。

常見問題 FAQ

Cursor 與 VS Code 有什麼不同？

Cursor 基於 VS Code，保留所有功能與擴充套件。最大差異在於深度整合 AI 功能，可視為「內建 AI 助手的 VS Code」。

Cursor 免費版夠用嗎？

每月 2,000 次補全與 500 次 Chat 訊息，輕中度開發者夠用。大量使用建議升級 Pro（$20/月）。

可以用自己的 API Key 嗎？

可以。在 Settings > Models 中輸入自己的 OpenAI 或 Anthropic API Key，使用量不計入免費配額。

VS Code 擴充套件能繼續用嗎？

絕大多數可以，包括 ESLint、Prettier、GitLens 等。少數依賴 VS Code 專有 API 的可能無法運作。
